THE LITTLE ELSEWHERE — DECAP CMS SETUP

This is a small set of files to add to the ROOT of your existing GitHub repository. It does not replace the original CSS: the full original style block is retained unchanged in _layouts/default.html.

Files/folders included:
- admin/index.html and admin/config.yml: Decap CMS editor and your Turbo Site ID
- _config.yml and _layouts/: Jekyll rendering so published stories appear on the site
- index.html: homepage story list using the existing magazine styling
- _posts/ and images/uploads/: folders where Decap will save stories and photographs

IMPORTANT: Upload/merge these files into the ROOT of ridhigupta001/the-little-elsewhere. Do not upload the outer folder itself. Do not delete or replace your existing CSS manually. The provided _layouts/default.html contains the existing CSS block. GitHub Pages may take a few minutes to rebuild after committing.
