THE LITTLE ELSEWHERE — FIRST STATIC VERSION

The original visual stylesheet is preserved unchanged.
No stories or publishing/editor interface are included.

Publish:
1. Create a public GitHub repository named the-little-elsewhere.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, branch main, folder /(root), then Save.
5. Test the github.io address before connecting ridhiguptathinks.in.

Security notes:
- Static HTML only: no server, database, login, public editor, upload endpoint,
  localStorage publishing store, API keys, or third-party JavaScript.
- The decorative fonts are still loaded from Google Fonts, as in the original.
- The original inline CSS and small inline script are retained. GitHub Pages
  does not provide arbitrary security response headers by itself.
- Enable GitHub account two-factor authentication and keep repository access
  limited to your own account.
- Connect the custom domain only after the GitHub Pages URL is working.
